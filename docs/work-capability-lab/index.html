Work SDK Lab

Develop like a Work author, inspect like a platform engineer.

This directory Work imports the npm SDK from an ESM CDN, loads local CSS, JS, and JSON assets, then exercises runtime context, scoped reads, viewer authorization, and prompt submission exactly the way a no-build Work would.
