# Examples

Sample assets for Cohub guides and demos.

| Path | What it shows |
|---|---|
| `generations/` | Multimodal generation model declaration samples |
| `new-chat-background/` | Custom new-chat App background example |
| `app-capability-lab/` | Published App runtime lab (live context, App Surface state, auth, files, sessions, commerce) |
| `app-capability-lab/whale-shrine/` | Full commerce + prompt App demo |
| `desktop-surfaces/milk-frog/` | Overlay desktop companion: sprite animation, chatting with the current session, roam/dock hit regions |

These are reference samples. Paths inside a published App (for example Space-root file paths) may need adjusting to match how you upload them into a Space.
